En este trabajo se realizaron diferentes aproximaciones y pruebas con HTML y CSS, explorando distintas formas de organizar y presentar la información dentro de una página web. Se trabajó con varios documentos HTML, cada uno con distintas propuestas y elementos.

Los componentes de las páginas

Galería: realicé una galería interactiva donde se presentan distintos trabajos mediante imágenes que permiten acceder a una página HTML individual de cada trabajo práctico, con información y contenido propio.

Formulario: realicé una aproximación a un formulario con distintos campos para completar información y opciones para seleccionar, incorporando diferentes elementos de interacción para el usuario.

También se trabajó con distintas etiquetas HTML y selectores CSS, buscando organizar los contenidos y darles una presentación visual.


Información sobre el diseño
La paleta cromática utilizada gira alrededor del blanco puro (#FFFFFF), una tonalidad borgoña (rgb(101, 16, 39)) y un blanco rosado (#F0DACC). Estos tonos se utilizaron para generar contraste y mantener una continuidad visual entre las distintas páginas.
